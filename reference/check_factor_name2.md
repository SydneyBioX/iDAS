# Check the iDAS_2F input factors' name

This function will be no longer be used.

## Usage

``` r
check_factor_name2(
  factor1_name,
  factor2_name,
  random_effect_name,
  factor1,
  factor2,
  random_effect
)
```

## Arguments

- factor1_name:

  A string for the first factor variable's name.

- factor2_name:

  A string for the second factor variable's name.

- random_effect_name:

  A string for the random effect term's name.

- factor1:

  A vector of the first factor variable.

- factor2:

  A vector of the second factor variable.

- random_effect:

  A vector of the random effect term variables.

## Value

A list of each factor's name and values.
