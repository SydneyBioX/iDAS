# Check the iDAS_3F input factors' name

This function will be no longer be used.

## Usage

``` r
check_factor_name3(f1name, f2name, f3name, randomname, f1, f2, f3, random)
```

## Arguments

- f1name:

  a string of factor 1's name

- f2name:

  a string of factor 2's name

- f3name:

  a string of factor 3's name

- randomname:

  a string of random effect term's name

- f1:

  A vector of factor 1 variables.

- f2:

  A vector of factor 2 variables.

- f3:

  A vector of factor 3 variables.

- random:

  A vector of random effect term variables.

## Value

A list of each factor's name and values
